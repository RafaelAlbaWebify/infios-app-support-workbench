# INFIOS Roadmap

## M1 - Backend MVP

Goal: one strong Application Support scenario.

- FastAPI backend.
- Pydantic incident model.
- HTTP 500 after login sample.
- Analyzer rules.
- Markdown report generator.
- Tests.
- Safety boundaries.
- Interview-ready README.

## M2 - More Support Scenarios

Add scenarios for:

- HTTP 401 unauthorized.
- HTTP 403 forbidden.
- HTTP 404 not found.
- HTTP 409 conflict.
- HTTP 429 rate limited.
- HTTP 502 bad gateway.
- HTTP 503 service unavailable.
- Slow login with dependency timeout.
- Database query timeout from support perspective.

## M3 - Stronger Application Support Evidence

- Log snippet parser for sample logs.
- Correlation ID timeline.
- User impact classifier.
- Escalation templates.
- RCA quality checks.

## M4 - Portfolio Demo

- CLI report generation.
- HTML report export.
- Screenshot/demo package.
- Interview script.
- Public-safe sample evidence pack.
